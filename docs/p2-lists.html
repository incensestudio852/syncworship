第 2 頁 · 敬拜清單

把程序排好，一按上台。

清單就是當日的敬拜程序。每首歌可設定服務調性、速度與段落流程， 排好次序之後按推送，全隊的畫面同時跟上。

A B C D E
A
開啟舞台模式

進入全螢幕舞台。手機、平板、電腦都可以，全隊看同一個畫面。

B
Live 狀態

顯示台上正在唱的詩歌，以及是哪部裝置推送。一眼知道進度走到哪裡。

C
推送

即時送歌上台。隊友會收到提示，自己決定何時切換，不必中斷正在唱的段落。

D
把手與序號

曲目次序與拖曳把手合併成一欄，騰出空間給歌名。點一下前移，長按後移。

E
調性、速度、段落

每首歌可設定服務調性、BPM 與段落流程。加入時自動代入詩歌庫的數值，不用重打。

段落流程提示

流程寫成 Intro → V1 → C → V2 → C×2 → B → C×3。 每個段落可以標上 1–10 級的動態，台上顯示時會用顏色區分安靜與全開。

清單超過三個月會自動清理，需要的話記得先複製一份。
